Zed xetk

A personal build of the Zed editor with a few extra features. Not affiliated with or supported by Zed Industries.

What this build adds, and how to turn it on

Installing

Builds are not notarized. On macOS the first launch needs a right-click and Open, or:

xattr -cr "/Applications/Zed xetk Nightly.app"

Once installed, the app checks this site for updates and installs a build only if its signature and checksum match.

It shares its settings and history with a regular Zed install on the same Mac, so avoid running both at once.
