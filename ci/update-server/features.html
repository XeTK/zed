What this build adds

Everything here is on top of upstream Zed. Settings go in your user settings.json (cmd-,) unless it says project, and most also appear in the settings UI.

Projects and windows

Window accent color per project

Tint a project's title bar so windows are easy to tell apart.

Add a hex color to the project's .zed/settings.json, or set it in the settings UI:

{ "window_accent_color": "#3b82f6" }

The project's name in the sidebar gets the same color, with text that stays readable on it. Unset means the normal theme title bar.

Next and previous project

Switch between the projects in a window from the keyboard.

cmd-alt-] and cmd-alt-[ on macOS, ctrl-alt-] and ctrl-alt-[ on Linux and Windows. The actions are multi_workspace::NextProject and PreviousProject.

Reorder projects in the sidebar

Drag a project's header row up or down in the sidebar to reorder the projects.

Agent panel

Message timestamps

When each message was sent. Saved with Zed agent threads.

Hover a message to see its time, and hover the time for the full date. To always show it:

{ "agent": { "message_timestamps": "always" } }

Values are "on_hover" (default) and "always". Threads saved before this feature, and history loaded from external agents, show no time.

Elapsed time on tool calls

Every running tool call shows how long it has been running once it passes a second, not only terminal commands. No setting.

Threads as tabs

Move a conversation out of the panel into the editor area.

  • Thread menu in the panel: Move Thread to New Tab hands the active thread to a tab and gives the panel a fresh thread.
  • Thread menu: New Thread in Tab starts a new thread directly in a tab.
  • Right-click a thread in the sidebar: Open Thread in Tab.

Tabs behave like any other tab: reorder, drag between panes, split. They come back after a restart.

Unsent draft flag

A thread whose message box holds unsent text shows a pencil icon in the sidebar. The text is kept across restarts. No setting.

Expand image cards

Off by default.

Tool call cards that return an image, such as a screenshot, expand on their own the first time the image arrives:

{ "agent": { "expand_image_card": true } }

If you collapse the card again it stays collapsed.

Archive search

The threads archive matches and highlights the title shown on screen, including titles you renamed.

Stability and performance

Child processes are cleaned up

MCP context servers and external agents are killed along with everything they started, including processes that detached from them, when they are dropped and when Zed quits. Before, some could be left running after Zed exited.

Smaller fixes

Releasing UI focus handles and recomputing bracket colors no longer do needless work on every frame or theme change.

Updates

Signed updates from this site

The app checks zed.xetk.co.uk for a new build and installs it only if the Ed25519 signature and the SHA-256 checksum match. It has its own name and bundle id, so it can sit next to an official Zed. Nightly builds follow every change to main; stable follows tagged releases.
